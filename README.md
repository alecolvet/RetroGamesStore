# Retro Games Store 🎮

Projeto acadêmico desenvolvido em C# para o Checkpoint 3
da disciplina C# Development, do curso de Engenharia de Software.

## Funcionalidades

- Tela de abertura com identidade visual retrô.
- Menu principal de navegação.
- Catálogo de jogos clássicos.
- Cadastro de novos jogos.
- Registro de pedidos.
- Validação de estoque.
- Atualização automática do estoque após a venda.
- Relatório detalhado de vendas.
- Cálculo do faturamento total.
- Resumo de estoque e alertas de estoque baixo.

## Tecnologias

- C#
- .NET
- Visual Studio
- Git e GitHub

## Como executar

1. Abra o arquivo RetroGamesStore.csproj no Visual Studio.
2. Aguarde o carregamento do projeto.
3. Pressione Ctrl + F5 para executar.

## Observação

Esta versão utiliza interface de console e mantém os dados
em memória durante a execução do programa.
